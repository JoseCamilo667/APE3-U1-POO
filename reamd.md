## 🎯 Objetivo del proyecto

Desarrollar cuatro problemas utilizando el lenguaje de programación Java, aplicando los fundamentos de la Programación Orientada a Objetos y organizando el código mediante las carpetas `domain` y `view`.

## 📖 Descripción del proyecto

Este repositorio contiene la resolución de cuatro problemas correspondientes a la actividad APE de la asignatura Programación Orientada a Objetos.

El proyecto separa la lógica de cada ejercicio de la interacción con el usuario, facilitando la lectura, comprensión, ejecución y mantenimiento del código.

### 🛠️ Tecnologías utilizadas

- ☕ **Java:** lenguaje de programación.
- 💻 **IntelliJ IDEA:** entorno de desarrollo recomendado.
- 🐙 **GitHub:** almacenamiento y documentación del proyecto.

## ▶️ Instrucciones de ejecución

1. Clonar o descargar el repositorio de GitHub.
2. Abrir el proyecto en IntelliJ IDEA.
3. Configurar el JDK de Java.
4. Verificar que los paquetes coincidan con las rutas de los archivos.
5. Ejecutar `Main.java`.
6. Seleccionar el problema que se desea resolver.
